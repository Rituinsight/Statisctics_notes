# Statisctics_notes

. What is Statistics?
Definition: Statistics is the science of collecting, organizing, analyzing, interpreting, and presenting data to make better decisions.
Example: A company collects the sales data of the last 12 months to find which month had the highest sales.
Importance of Statistics
Helps in making better decisions.
Identifies trends and patterns.
Supports business and research.
Used in Data Analytics, AI, Finance, Healthcare, Marketing, and Education.
2. What is Data?
Definition: Data is a collection of facts, figures, observations, or information.
Example: Marks: 85, 90, 78, 88, 95
3. Types of Data
A. Qualitative (Categorical) Data
Data that describes qualities or categories.
Examples:
Gender
Blood Group
City
Colour
B. Quantitative (Numerical) Data
Data represented by numbers.
(i) Discrete Data
Countable values.
Examples:
Number of Students
Number of Cars
Number of Employees
(ii) Continuous Data
Measurable values.
Examples:
Height
Weight
Temperature
Salary
4. Population vs Sample
Population
The complete group you want to study.
Example: All students in a college.
Sample
A smaller group selected from the population.
Example: 100 students selected from that college.
Population
Sample
Entire group
Part of the group
Larger size
Smaller size
More expensive to study
Less expensive and faster
5. Variables
Definition: A variable is any characteristic that can change or take different values.
Examples:
Age
Height
Weight
Salary
Marks
Types of Variables
Independent Variable
The variable that influences another variable.
Example: Hours studied.
Dependent Variable
The variable whose value depends on the independent variable.
Example: Exam marks.
6. Scales of Measurement
1. Nominal Scale
Used for names or categories.
Examples:
Gender
Blood Group
City
Colour
2. Ordinal Scale
Used for ranking or ordering.
Examples:
1st, 2nd, 3rd Rank
Poor → Fair → Good → Excellent
3. Interval Scale
Equal intervals, but no true zero.
Examples:
Temperature (°C)
Calendar Years
4. Ratio Scale
Equal intervals with a true zero.
Examples:
Height
Weight
Age
Income
